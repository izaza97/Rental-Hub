# Database — PS Rental Hub (Admin + Client Next.js)

**Sistem database resmi: Supabase PostgreSQL.** Seluruh API (admin & client) terhubung
ke database yang sama melalui `DATABASE_URL` + driver `pg`.

## Isi folder

| File | Status | Fungsi |
|---|---|---|
| `supabase/migrations/0001_init.sql` | ✅ **Aktif** | Skema 11 tabel + FK + index + 3 view + seed data. Dijalankan di Supabase SQL Editor. |
| `scripts/migrate-sqlite-to-supabase.mjs` | ✅ **Aktif** | Migrasi data dari `ps_rental_hub.db` (SQLite lama) ke Supabase, id & FK dipertahankan. |
| `schema.prisma` | ✅ Aktif (opsional) | Definisi ORM Prisma, `provider = "postgresql"`, `url = env("DATABASE_URL")`. |
| `ps_rental_hub.sql` | ⚠️ Legacy | Arsip DDL MySQL lama (XAMPP/phpMyAdmin) — hanya referensi, tidak dipakai aplikasi. |
| `ps_rental_hub.db` | ⚠️ Legacy | Database SQLite lama — hanya sumber data untuk script migrasi. |

## Setup Supabase (sekali saja)

1. Buat project di <https://supabase.com> → **SQL Editor → New query**.
2. Paste seluruh isi `supabase/migrations/0001_init.sql` → **Run**.
3. Salin connection string (**Pooler, port 6543**) ke `DATABASE_URL` di
   `.env.local` masing-masing aplikasi (lihat `../DEPLOYMENT-VERCEL.md`).

## Migrasi data lama (SQLite → Supabase)

```bash
cd database
npm install --no-save better-sqlite3 pg
DATABASE_URL="postgresql://...pooler.supabase.com:6543/postgres" \
  node scripts/migrate-sqlite-to-supabase.mjs
```

Tambahkan `--reset` bila ingin menghapus isi Supabase terlebih dahulu lalu load penuh.

## Catatan kompatibilitas (MySQL/SQLite → PostgreSQL)

- `ENUM` → `TEXT` + `CHECK` (nilai identik dengan aplikasi)
- `LIKE` case-insensitive → aplikasi memakai **`ILIKE`**
- `AUTO_INCREMENT` → `GENERATED BY DEFAULT AS IDENTITY` (insert id eksplisit tetap boleh)
- `lastInsertRowid` → `INSERT ... RETURNING id`
- kolom waktu → `TIMESTAMP` (format string `YYYY-MM-DD HH:MM:SS`, zona runtime server)
